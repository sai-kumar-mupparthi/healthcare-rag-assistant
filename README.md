# Healthcare RAG Knowledge Assistant

**Repo name on GitHub:** `healthcare-rag-assistant`
**Context:** Machine Learning Engineer @ Kaiser Permanente (Feb 2024 – Present)

> Case study of production work. This repo describes the system design and results — it contains no employer code or data.

## What it is
A Retrieval-Augmented Generation (RAG) system that gives clinical staff self-serve, semantic access to healthcare policies and clinical guidelines — instead of manually searching documents.

## What I built
- RAG workflows for semantic retrieval over healthcare policies and clinical guidelines
- Embedding + vector search pipeline using FAISS and Pinecone
- LLM-powered internal knowledge assistant integrated into healthcare operations

## Results
- **40% reduction** in information search time
- Serves **500+ clinical staff** members

## Tech stack
Python · LangChain · LlamaIndex · LLMs · Embeddings · FAISS · Pinecone · FastAPI

## Skills demonstrated
RAG architecture · Semantic search · Vector databases · Prompt engineering · LLM application development
